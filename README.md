# POKE LIFE

`POKE LIFE` is a two-level 2D platformer I developed from May through August 2025 for DIG 2632 — Creating Mobile Games at the University of Florida in Gainesville. Working from the course's starter gameplay framework, I designed the complete player journey and integrated the scenes, systems, assets, interface, and progression into a finished Windows build.

## What I built

- Designed two full gameplay levels containing nearly 500 configured Unity GameObjects.
- Created a complete title-to-credits flow with title, gameplay, ending, and credit scenes.
- Assembled tilemap environments with moving platforms, patrol paths, hazards, portals, checkpoints, and layered backgrounds.
- Integrated ranged combat, enemy encounters, health and healing, collectible fruit, battle and collection counters, and level transitions.
- Configured dialogue, character and enemy animation, UI, 2D lighting, post-processing, parallax, and sound cues.
- Iterated on pacing, visual hierarchy, traversal, feedback, and difficulty across the full summer semester.

## Repository contents

- `Assets/Scenes/` — the five-scene game flow, including both designed levels
- `Assets/Prefabs/` — configured UI and gameplay prefabs
- `Assets/Scripts/Structural Scripts/` — speaker-library configuration used by the dialogue system
- `ProjectSettings/` and `Packages/` — the archived Unity configuration and package manifest
